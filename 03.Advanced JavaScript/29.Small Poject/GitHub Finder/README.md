# 🔍 GitHub Finder

A web application that allows users to search for GitHub profiles and explore developer information using the GitHub API.

## 🚀 Live Demo

[View Live Project](https://githubfinder-azure.vercel.app/)

## 📸 Features

- Search GitHub users by their username.
- View user profile information.
- Display profile picture and GitHub profile link.
- View public repositories and other account details.
- Fetch real-time user data using the GitHub API.
- Simple and responsive user interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub REST API

## ⚙️ Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/RupeshNipanikar/Fullstack-development/new/main/03.Advanced%20JavaScript/29.Small%20Poject/GitHub%20Finder
   ```

2. Navigate to the project directory:

   ```bash
   cd "GitHub Finder"
   ```

3. Open `index.html` in your browser.

## 🔗 API Used

[GitHub REST API](https://docs.github.com/en/rest)

Used to retrieve GitHub user profile information and public repository data.
